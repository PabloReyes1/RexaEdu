# 11 · Benchmark y funcionalidades Plus

## 1. Plataformas de referencia

| Plataforma | Tipo | Lo que hace bien | Oportunidad para nosotros |
|---|---|---|---|
| **Google Classroom** | LMS gratuito | Muy simple para publicar tareas y calificar; integrado a Drive. | No es un sistema de gestión escolar: sin estructura de colegio, boletas, padres limitados (solo resúmenes por correo), promedios básicos. |
| **Microsoft Teams for Education** | LMS + comunicación | Tareas, Class Notebook, integración Office. | Complejo para padres; no gestiona la estructura académica completa. |
| **Moodle** | LMS open source | Muy configurable, cuestionarios, rúbricas, libro de calificaciones potente. | Pesado, curva de aprendizaje alta, interfaz anticuada, requiere hosting y soporte técnico. |
| **Canvas / Schoology** | LMS comercial | Gradebook avanzado, apps móviles, portal de padres. | Precio alto, orientado a EE. UU., poco adaptado a la estructura y forma de evaluar de Latinoamérica. |
| **PowerSchool / Infinite Campus** | SIS (Student Information System) | Gestión integral: matrícula, asistencia, boletas, padres. | Enterprise, caro, en inglés, implementación larga. |
| **ClassDojo / Seesaw** | Comunicación familia-escuela | Excelente comunicación con padres, portafolios en primaria. | No manejan calificaciones ni estructura académica. |
| **Plataformas regionales** (Phidias, Cibercolegios, Educamos, Alexia, Idukay, Schoolnet y similares) | SIS + LMS para Latam/España | Adaptadas a boletas locales, pagos, comunicación. | Varias son costosas o complejas; pocas usan **WhatsApp** como canal principal de consulta para padres. |

**Conclusión:** existe espacio para un producto que combine **SIS ligero + LMS sencillo + WhatsApp nativo para padres**, adaptado a la forma de trabajo de colegios latinoamericanos (zona/examen, bimestres, profesor titular) y con implementación en días, no meses.

## 2. Funcionalidades base que el mercado da por hecho

Estas no venden por sí solas, pero **su ausencia hace perder ventas**:

- Importación desde Excel.
- Boletas en PDF con el formato del colegio.
- Libro de calificaciones exportable.
- Calendario escolar.
- Uso desde el celular.
- Anuncios con segmentación.
- Roles y permisos claros.

## 3. Funcionalidades Plus (diferenciadores para vender)

### 3.1 Familias y WhatsApp
| Funcionalidad | Valor de venta |
|---|---|
| **Consultas por WhatsApp** (MVP) | "Los padres se enteran sin descargar ninguna app." |
| **Resumen semanal automático** por WhatsApp | Padres involucrados sin esfuerzo del profesor. |
| **Alertas tempranas**: promedio bajo el mínimo, tareas no entregadas acumuladas, ausencias repetidas | Reduce reprobación; argumento fuerte para dirección. |
| **Asistente con IA** en WhatsApp ("¿qué le falta entregar a Luis esta semana?") | Experiencia moderna; diferenciador claro. |
| **Confirmación de lectura** de circulares y **autorizaciones digitales** (permiso para excursión: "Sí autorizo") | Elimina papeles firmados. |
| **Citas con profesores** (reservar horario de atención) | Organiza las reuniones de padres. |
| **Portal / app de padres** de solo lectura | Para quienes prefieren la web. |

### 3.2 Académico
| Funcionalidad | Valor |
|---|---|
| Rúbricas reutilizables | Calificación más justa y rápida. |
| Exámenes en línea autocalificables | Ahorra tiempo al profesor. |
| Banco de actividades y copia entre ciclos | Reutilización año con año. |
| Simulador "¿qué nota necesito?" para alumnos | Motivación y autogestión. |
| Detección de plagio / similitud entre entregas | Integridad académica. |
| Planificación docente (planes de clase, competencias, indicadores de logro) | Muchos ministerios de educación lo exigen. |
| Portafolio digital del alumno (primaria) | Evidencias visibles a padres. |
| Insignias y logros (gamificación) | Engagement de alumnos. |
| Integración con Google Workspace / Microsoft 365 (inicio de sesión, Drive/OneDrive para adjuntos, Meet/Teams) | Colegios que ya los usan. |

### 3.3 Gestión del colegio
| Funcionalidad | Valor |
|---|---|
| **Tablero de dirección** con indicadores: rendimiento por grado/materia, profesores con notas atrasadas, alumnos en riesgo, asistencia | Decisión basada en datos. |
| Asistencia con QR / carné | Fase 2 con valor agregado. |
| Pagos en línea con recordatorios por WhatsApp | Mejora la cobranza: argumento económico fuerte. |
| Admisiones e inscripción en línea | Captación de alumnos nuevos. |
| Biblioteca, enfermería, transporte escolar | Módulos adicionales por plan. |
| Reportes oficiales con formato del ministerio de educación por país | Gran ahorro de tiempo administrativo. |
| Expediente digital del alumno | Historial completo de varios años. |
| Encuestas a padres/alumnos | Medición de satisfacción. |
| Dominio propio y marca blanca | Plan premium. |
| App móvil nativa con notificaciones push | Fase futura. |

## 4. Propuesta de planes (para validar comercialmente)

| Plan | Incluye | Cobro sugerido |
|---|---|---|
| **Básico** | Portales admin/profesor/alumno, tareas, calificaciones, boletas, anuncios, foros | Por alumno activo / mes |
| **Familia** | Básico + WhatsApp para padres (con paquete de mensajes) + alertas | Por alumno activo / mes |
| **Completo** | Familia + asistencia + pagos en línea + tablero de dirección | Por alumno activo / mes |
| **Enterprise** | Completo + número de WhatsApp propio, dominio propio, integraciones, soporte prioritario | Cotización |

Cobro por alumno activo es el estándar del sector y escala con el tamaño del colegio. Incluir costo de implementación/capacitación opcional.
